# Dashboard App 

## Description

Ce projet framework consiste à réaliser un design **glassmorphism**, en respectant la maquette fournie, ainsi qu'à intégrer un **background animé** à la page. Le projet implique également la consultation, l'intégration et l'adaptation de code trouvé sur CodePen.

## Objectifs

- Avoir un aperçu d'une doctrine de design réel : le **glassmorphism**.
- Intégrer un **background animé** à une page web pour apporter plus de dynamisme.

## Spécifications

- Utilisation exclusive de classes issues de frameworks CSS (pas de CSS personnalisé).

## Technologies utilisées

- HTML5
- Framework CSS (Bootstrap)
- Background animé adapté depuis CodePen

## 📁 Ressources
